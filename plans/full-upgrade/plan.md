# Meterly 全面升级实施计划

## 约定

- 面向 1–20 台主机、100 个以内网站；Go + SQLite + 内嵌静态面板。
- 新版 `/api/v2`；旧中心、agent、数据库不兼容，旧库不自动删除或回填。
- 网站与 IP 分析聚焦源站日志，完整 IP 小时明细 365 天、分钟 48 小时，长期保留主机/网站汇总。
- 自动发现、配置同步、维护；升级必须由面板明确触发；不执行任意远程命令。
- 不操作生产、不安装数据库服务、不使用 Docker。本计划逐项完成后标记 ✅。

## 实施任务

- [x] ✅ 1. 新版协议、数据结构和兼容边界；采集持久化、解析、日志轮转和 CDN 归因。
- [x] ✅ 2. 完整 IP 数据、统一查询范围、筛选/分页/趋势/对比/CSV 与完整性说明。
- [x] ✅ 3. 自动发现、配置版本同步、主机管理、安装包、维护/备份/告警与受控升级。
- [x] ✅ 4. ES Modules 面板：总览、网站、IP、主机、对账、系统；日期→网站→IP 路径、URL 状态、主题与移动端。
- [x] ✅ 5. 文档、部署模板、回归和浏览器验证；记录实际测试结果与运行边界。

## 验收

- 超过旧 Top-N 的 IP 完整保留，分页/排行/曲线/导出总量一致。
- 日期、时区、最近一小时、等长比较、保留期和不可用指标正确。
- CDN/直连/伪造头/IPv6/缺字段归因可解释。
- 写入故障、重复发送、重启、轮转、异常行和热配置不静默漏计。
- 自动发现新增源，手动禁用优先，无效配置保持上一有效版本。
- 独立/重复安装、指定版本、升级失败回滚、TLS 路由均有验证。
- 浏览器验证日期→网站→IP→返回、刷新/前进后退、竞态、错误和移动端。
- Go vet/race、项目 JS 测试，改动 Shell/Actions/文档时做对应条件检查。
